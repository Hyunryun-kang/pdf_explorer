## Opencode Agent Orchestration

Opencode 에서 각 분야별 에이전트가 각자 역할에 충실하도록 업무 분배를 하고 관리하도록 하는 시스템.

### Agents

| 이모지 | 에이전트 이름 | 한글 이름 | 역할 요약 |
|---|---|---|---|
| 🔍 | Sherlock | 셜록 | 사용자의 요구사항을 명확하게 하고, 전체적인 개념을 확립 |
| 🛠️ | Maker | 메이커 | 요구사항 문서를 보고, 실제 코드 작성을 이행 |
| 🎨 | Picasso | 피카소 | UI/UX 디자인을 텍스트 형태로 제공 |
| 📡 | Rader | 레이더 | 자료 검색 전문가 (웹 검색, 문서, 자료 탐색) |
| 💡 | Spark | 스파크 | 창의적인 아이디어를 도출 |
| ✍️ | Typist | 타이피스트 | 문서 작성 전문가 |
| 🎬 | Director | 디렉터 | Sherlock의 계획을 검토 |
| ⚖️ | Judge | 저지 | Sherlock의 계획의 실패를 면밀하게 분석하여 재구성 |

---

### 🔍 Sherlock (셜록)

Sherlock은 사용자의 요구사항을 분석하고 명확하게 정의하는 역할을 담당합니다. 복잡하거나 모호한 요청을 체계적으로 정리하여 다른 에이전트들이 이해하고 실행할 수 있는 구체적인 작업 계획으로 변환합니다. 프로젝트의 전체적인 개념을 확립하고, 작업의 방향성을 제시하는 핵심 에이전트입니다.

### 🛠️ Maker (메이커)

Maker는 실제 코드 작성을 담당하는 에이전트입니다. Sherlock이 정리한 요구사항 문서를 기반으로 기능을 구현하고, 버그를 수정하며, 코드 리팩토링을 수행합니다. 다양한 프로그래밍 언어와 프레임워크에 대한 전문 지식을 바탕으로 안정적이고 효율적인 코드를 작성합니다.

### 🎨 Picasso (피카소)

Picasso는 UI/UX 디자인을 텍스트 형태로 제공하는 에이전트입니다. 사용자 인터페이스의 레이아웃, 컴포넌트 구조, 스타일 가이드 등을 설계하고 제안합니다. 시각적 요소를 코드로 표현하여 개발자가 쉽게 구현할 수 있도록 상세한 디자인 명세를 제공합니다.

### 📡 Rader (레이더)

Rader는 자료 검색 전문가로서 웹 검색, 문서 탐색, 자료 수집을 담당합니다. 프로젝트에 필요한 정보를 신속하게 찾아내고, 관련 문서나 레퍼런스를 정리하여 제공합니다. 최신 기술 트렌드, 라이브러리 문서, API 사양 등 다양한 정보 소스를 활용합니다.

### 💡 Spark (스파크)

Spark는 창의적인 아이디어를 도출하는 에이전트입니다. 문제 해결을 위한 새로운 접근 방식을 제안하고, 혁신적인 기능이나 개선점을 발굴합니다. 브레인스토밍과 아이디어 발전 과정을 통해 프로젝트에 새로운 가치를 더합니다.

### ✍️ Typist (타이피스트)

Typist는 문서 작성 전문가로서 기술 문서, README, API 문서, 사용자 가이드 등 다양한 문서를 작성합니다. 명확하고 이해하기 쉬운 문장으로 복잡한 기술 내용을 설명하며, 일관된 문서 스타일과 포맷을 유지합니다.

### 🎬 Director (디렉터)

Director는 Sherlock이 수립한 계획을 검토하고 평가하는 역할을 담당합니다. 작업 계획의 타당성, 실현 가능성, 효율성을 분석하여 피드백을 제공합니다. 프로젝트가 올바른 방향으로 진행되고 있는지 감독하고 조율합니다.

### ⚖️ Judge (저지)

Judge는 계획의 실패 요인을 면밀하게 분석하고 재구성하는 에이전트입니다. 문제가 발생했을 때 원인을 파악하고, 개선된 대안을 제시합니다. 객관적인 시각으로 결과물을 평가하고, 품질 향상을 위한 구체적인 방안을 도출합니다.
